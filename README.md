# plp-da-a2-rainfall-advisory

- This project cleans rainfall data, analyzes rainfall patterns using NumPy, and generates a planting advisory for five Kenyan counties.
- Run `rainfall_analysis.ipynb` from top to bottom after installing the requirements listed in `requirements.txt`.
- Planting is recommended during the highest two‑month rainfall windows identified for each county, while noting that Machakos data contained imputed values.
